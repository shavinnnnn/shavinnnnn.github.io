# Kumarasinghe S.N | E-Portfolio

Personal e-portfolio built for **SC1172: Introduction to Information Technology**
(BSc (Hons) in Biotechnology, SLIIT) using **GitHub Pages, Markdown and HTML/CSS**.

## Live Website
https://GITHUB_USERNAME.github.io/

## Sections
- **Home**: introduction, photograph and CV download
- **About Me**: short paragraph about me
- **Educational Qualifications**: higher education and secondary education
- **Skills**: laboratory techniques, communication, teamwork, Microsoft Office
- **Work Experience and Other Qualifications**
- **Projects**: academic projects
- **Hobbies**
- **Resume**: downloadable PDF version
- **Contact**: email address and social links

## Project Structure
```
├── index.html     # Page structure and content
├── style.css      # Styling (dark blue biotechnology theme)
├── script.js      # Mobile menu and active link highlighting
├── images/        # Profile photo and section images
├── files/CV.pdf   # Downloadable resume
└── README.md      # Project documentation
```

## How to Run Locally
